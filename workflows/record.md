# Record

**Input:** completed review, validation evidence, and decisions made during the phase.

**Do:** update `TASKS.md` only for validated work. Update the roadmap when a phase exits. Record durable reasoning, lessons, and project links in the private Obsidian knowledge hub. Keep the repository contract aligned with behavior.

For work that moves between machines or harnesses, create a portable handoff containing the goal, authority boundary, current state, evidence, risks, and next action. Reference specs, tickets, commits, and diffs instead of copying them.

**Output:** an inspectable repository state and a concise durable record.

**Gate:** do not create records that expose secrets, private topology, raw session history, or unverified claims.

Related: [Obsidian](../kb/obsidian.md) and [cross-machine work](../kb/cross-machine-work.md).
