# Public safety

Assume every committed file, image, link, and example will be read without private context.

## Never publish

- credentials, tokens, keys, signing material, or authentication configuration;
- network addresses, account identifiers, private domains, or infrastructure inventories;
- vault notes, session logs, raw agent transcripts, device logs, OCR text, or private screenshots;
- real cost, environment, or deployment details that identify a private system;
- copied third-party text or skills without license review.

Use fictional names and placeholders. Examples should be runnable in shape without revealing a real environment.

## Review before commit

Search changed files for URLs, home directories, IP-like values, account-length numbers, secret-looking assignments, private note links, screenshots, and generated files. Inspect image metadata and any embedded examples. Confirm every external link is intentional and every local link resolves.

The approved workflow screenshot is a documented exception. It does not make other screenshots safe by default.
