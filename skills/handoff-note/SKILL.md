# Handoff note

Write a pointer to current state, not a transcript.

1. Confirm the goal, non-goals, revision, and exclusively owned paths.
2. Record decisions with their evidence or constraint.
3. Cite checks that ran, their result, and where their output can be found. State skipped checks plainly.
4. Name one next safe action plus unresolved risks and unknowns.
5. Remove credentials, private-note content, local absolute paths, hostnames, network addresses, account identifiers, and machine inventory. Use portable placeholders where a receiver must supply local details.

Follow the repository's handoff format when one exists. Otherwise use: goal, current state, decisions, evidence, next action, and risks.

Do not claim completion, copy session history, or grant the receiver wider permissions than the original task.
