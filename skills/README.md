# Original skill catalog

These small skills were written for this repository. They use the common `SKILL.md` shape, but clients differ in how they discover and invoke skills.

| Skill | Use it for | Output |
|---|---|---|
| [`context-scout`](context-scout/SKILL.md) | Starting a bounded repository task | Short evidence-backed context brief |
| [`evidence-check`](evidence-check/SKILL.md) | Verifying a claimed change | Acceptance-to-evidence table |
| [`handoff-note`](handoff-note/SKILL.md) | Pausing or transferring work | Portable handoff pointing to source-of-truth artifacts |

Install or copy a skill only after reviewing it. Repository instructions outrank a skill, and a skill never grants permission to merge, deploy, access secrets, or widen scope.
