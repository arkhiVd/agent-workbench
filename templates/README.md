# Templates

Copy only the files your repository needs. Replace every angle-bracket placeholder, remove irrelevant sections, and record unknowns instead of inventing facts.

- [`AGENTS.md`](AGENTS.md): short operating contract for coding agents
- [`SPEC.md`](SPEC.md): requirements, boundaries, and acceptance criteria
- [`ROADMAP.md`](ROADMAP.md): reviewable phases and exit gates
- [`TASKS.md`](TASKS.md): current execution state
- [`handoff.md`](handoff.md): cross-session or cross-machine handoff
- [`visual-contract.md`](visual-contract.md): interface intent and rendered checks

Keep explanations outside `AGENTS.md`. Commands in a template become trustworthy only after they run in the target repository.
